Tính năng chính

Những thứ bạn cần để soạn và chia sẻ bài trình chiếu.

⚡

Editor 2 khung, preview thời gian thực

Soạn mã HTML bên trái, các slide hiện ngay bên phải. Con trỏ ở slide nào, preview sẽ nhảy tới slide đó.

🎨

Color picker giúp chọn màu nhanh

Mọi mã màu trong code hiện ô màu nhỏ; bấm vào để kéo-chọn màu, xem trước trực tiếp.

🗂️

Nhãn & thu gọn từng slide

Gutter gắn nhãn ★, S1, S2.1… — bấm để đóng/mở code từng slide, luôn biết con trỏ đang ở slide thứ mấy.

🤖

AI hỗ trợ soạn slide

Mô tả yêu cầu bằng tiếng Việt, AI hỗ trợ sinh thẻ <section> hoàn chỉnh; kèm snippets cho slide, cột, công thức…

📐

Công thức Toán học KaTeX

Viết $...$, $$...$$ ngay trong slide và trong cả các bình luận ở Gallery.

🌐

Publish + Gallery công khai

Một nút xuất bản thành link chia sẻ; bài xuất hiện trong Gallery với lượt xem, thích, bình luận và trang cá nhân.

📦

Dashboard quản lý

Xem toàn bộ bài của bạn: xuất bản, đưa về nháp, đổi tên, xoá, theo dõi reactions và bình luận mới nhất.

💾

Xuất HTML / PDF

Tải bài trình chiếu về dạng file HTML chạy offline, hoặc in ra PDF ngay từ trình duyệt.

📥

Import tệp .pptx, .tex hay .md

Cho phép chuyển file PowerPoint (.pptx), file trình chiếu LaTeX Beamer (.tex) hoặc Markdown (.md) thành trình chiếu HeyShow.

Cách HeyShow hoạt động

Ba bước từ ý tưởng tới link trình chiếu.

Soạn slide

Mở trang thiết kế, tạo file nháp và viết các thẻ <section> — hoặc nhờ AI sinh giúp.

Xem trước & tinh chỉnh

Preview Reveal.js cập nhật ngay khi gõ; đổi màu bằng color picker, gập/mở slide, tìm kiếm nhanh.

Xuất bản & chia sẻ

Bấm Publish để có link công khai, theo dõi lượt xem và bình luận trong Dashboard.
